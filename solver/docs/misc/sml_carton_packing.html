SML carton (box_index 0) — packing result

Rough isometric sketch, hand-derived from the actual placements produced by Solver::pack for the test data in src/bin/test_request_2.rs (150×150×150mm SML carton, 8 identical 75mm cubes). The 8 cubes fill it exactly as a 2×2×2 stack — shown here as two separate flat layers rather than one combined 3D view, because a true single-viewpoint isometric render of a fully packed cube hides the far corner item behind the near one (they project to the same point). Not a live/interactive renderer — regenerate by hand if the test data changes.
